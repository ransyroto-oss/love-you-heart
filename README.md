# Love You Heart

A standalone animated webpage made with plain HTML, CSS, and JavaScript. It has
no package installation, build step, external image, or service requirement.

## Files to upload

Upload these four files to the **root of your GitHub repository**:

- `index.html`
- `styles.css`
- `script.js`
- `README.md`

They are all in this `github-ready` folder. Upload the files themselves so
`index.html` is at the repository root.

## Run it

Open `index.html` in a browser. The page also works as a static site on GitHub
Pages.

## Upload from an iPad

1. Download the ZIP and open the Files app.
2. Tap the ZIP file to extract it.
3. In your GitHub repository, choose **Add file → Upload files** and select
   `index.html`, `styles.css`, `script.js`, and `README.md` from the extracted
   folder.

Upload the extracted files, not just the ZIP, so GitHub Pages can find
`index.html` at the repository root.

To publish with GitHub Pages, open the repository's **Settings → Pages**, choose
**Deploy from a branch**, then select the `main` branch and `/ (root)` folder.
